# Getting help

PreviewMD is community-supported and currently maintained in personal time.
There is no guaranteed response time, but clear reports and kind follow-ups make
it much easier to help.

- **Something is broken:** open a bug report with a minimal document and exact
  reproduction steps.
- **You have an idea:** start a discussion or feature request and explain the
  user problem before the proposed control.
- **You want to contribute:** read `CONTRIBUTING.md`; unfinished ideas and draft
  pull requests are welcome.
- **You found a vulnerability:** follow `SECURITY.md` and report it privately.
- **You are building a port:** read `docs/PORTING.md` and open a port proposal.

Before sharing a Markdown document or log, remove private paths, names, email
addresses, tokens, document content, and other data you do not want permanently
visible in a public repository.

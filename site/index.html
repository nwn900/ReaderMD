What it renders

Everything GitHub Flavored Markdown can say — set the way print would say it. Each clipping below is captioned with its own source.

Three ways to set a page

New in PreviewMD: reading styles. One click in the toolbar re-sets the whole document — typefaces, page tone and accents — and every style carries its own dark grade.

Reader, not editor

PreviewMD does one job: it shows Markdown at its best. The chrome stays out of the way.

  • Preview · Split · SourceOne document, three ways to look at it.
  • Tabs, recents & pinningYour working set stays where you left it.
  • Drag & dropDrop a file on the window and read.
  • Reading-width rulerA live 560–1600 px measure, with narrow, comfortable, wide and table presets.
  • Outline navigationMove through the document by its headings.
  • SearchFind anything in the document, fast.
  • PDF exportThe page you see is the page you print.
  • Full dark modeFollows the system — like everything else here.

How PreviewMD is made

Native, all the way down

The shell is 100% SwiftUI — a real macOS toolbar, a real sidebar, real keyboard shortcuts. On this Mac, this very page is set in the same system face as the app’s chrome, because the app is the system’s chrome. It launches fast, weighs ~3.5 MB, and behaves the way Mac software should.

Sealed like a document

Rendering is fully offline. The engines that set your text are pinned, vendored copies embedded in the app itself:

markdown-it · Mermaid · KaTeX · Highlight.js — embedded, offline

What it never does:

  • No network access
  • No telemetry
  • No account
  • Documents never leave the Mac
